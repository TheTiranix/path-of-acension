# Mod compilado

`testamentodelacarne-0.1.0.jar` es el build ya compilado de este mod (tcorigenes + elementaldamage + testamentodelacarne, todo en un solo jar).

Para probarlo necesitás además el resto del modpack "TestamentodelaCarne" (los ~180 mods de terceros: Create, Twilight Forest, etc.) — esos no se distribuyen acá por tamaño y licencia. Instalá el mismo modpack por tu cuenta (mismas versiones, Forge 1.20.1-47.4.0) y reemplazá este jar en tu carpeta `mods/` por la versión más nueva cada vez que se actualice acá.

Recordatorio: el mod es propiedad de su autor (ver `LICENSE.txt` en la raiz del repositorio): se puede descargar y usar para jugar, pero no modificarlo ni redistribuirlo.
